Privacy policy

Last updated: 23 October 2026

What the app accesses

My Studio asks Google for two read-only permissions: View YouTube Analytics reports and View your YouTube account. It uses them only to show the signed-in user the analytics of their own YouTube channel. It cannot upload, edit or delete anything.

Where the data stays

The app runs on the user's own computer. The sign-in token and the reports it fetches are stored only there. Nothing is sent to any server other than Google's own APIs, and no data is sold, shared or used for advertising.

Google API Services

My Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

You can revoke the app's access at any time at myaccount.google.com/permissions. Deleting the app's local data folder removes everything it stored.
